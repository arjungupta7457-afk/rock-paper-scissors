# Rock Paper Scissors Game 🎮

A simple Rock Paper Scissors game made using Python.

## 📌 About

This is a beginner-friendly command-line game where the player plays Rock Paper Scissors against the computer.

The computer randomly chooses one option, and the game decides the winner based on the rules.

## 🛠️ Technologies Used

- Python
- Random module

## 🎮 How to Play

1. Run the Python program.
2. Choose one option:
   - Rock
   - Paper
   - Scissors
3. The computer will randomly select its choice.
4. The winner will be displayed on the screen.

## 📜 Game Rules

- Rock beats Scissors
- Scissors beats Paper
- Paper beats Rock
- Same choices = Tie

## ▶️ How to Run

Make sure Python is installed on your computer.

Run the following command:

```bash
python rock_paper_scissors.py
